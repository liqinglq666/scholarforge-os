# ScholarForge OS v1.1 — Document Ingestion

This release adds browser-side DOCX and text-based PDF ingestion before the existing PaperLens multi-agent workflow.

## Goals

- Import `.docx` and text-based `.pdf` research documents without first uploading the original file to ScholarForge servers.
- Detect common manuscript sections and let the author choose which section enters the review workspace.
- Preserve a clear boundary: equations, tables, figures, headers, footers, and scanned-image PDFs may require manual correction.
- Keep pasted-text input available as the universal fallback.

## Processing boundary

- DOCX text extraction uses Mammoth in the browser.
- PDF text extraction uses Mozilla PDF.js in the browser.
- The original file is not persisted by ScholarForge OS.
- Only the selected extracted text enters the existing review request after the user explicitly starts a workflow.
- Scanned PDF OCR is not included in this release.

## Acceptance flow

1. Open Document Import.
2. Choose a DOCX or text-based PDF up to 20 MB.
3. Inspect extraction warnings and detected sections.
4. Select one section or the full extracted text.
5. Choose translation, polishing, or pre-submission review.
6. Import it into PaperLens.
7. Verify the project title, section profile, terminology locks, and text before starting the four-agent workflow.
