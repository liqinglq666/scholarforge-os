# v1.0 Cloud Workspace Validation Checklist

## Local and guest modes

- [ ] Guest login still reaches the project hub.
- [ ] Translation, polishing, precheck, and reviewer-response workflows remain available.
- [ ] Local draft, history, backup, and restore remain functional.
- [ ] The cloud panel explains that guest/demo sessions remain browser-only.

## Supabase account mode

- [ ] Email account login exposes the cloud project panel.
- [ ] Missing database schema produces a setup message rather than breaking the app.
- [ ] “Sync current project” uploads only after explicit confirmation/action.
- [ ] “Migrate all local projects” groups local snapshots by project key.
- [ ] A second browser can restore the project after logging into the same account.
- [ ] Deleting a cloud project does not delete the browser-local copy.

## Isolation

- [ ] User A cannot select, update, or delete User B rows.
- [ ] Publishable key is used in the browser; service-role key is absent.
- [ ] RLS is enabled on `public.scholarforge_projects`.

## Build

- [ ] `npm run typecheck`
- [ ] `npm run build`
