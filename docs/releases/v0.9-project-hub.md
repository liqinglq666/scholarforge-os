# ScholarForge OS v0.9｜论文项目中心

## 版本目标

v0.9 将登录后的首屏从“直接进入单个编辑任务”升级为“论文项目中心”。

用户先了解当前草稿、最近任务、待处理证据和本地数据状态，再选择进入科研中译英、英文保守润色、投稿前预检或审稿回复工作流。

## 已实现功能

### 1. 登录后项目中心

- 当前草稿卡片
- 最近保存时间
- 百炼模型与应用版本状态
- 本机任务快照数量
- 待处理问题数量
- 历史平均准备度
- 浏览器本地数据占用

### 2. 四种工作流模板

每种模板提供两种入口：

- 空白任务
- 示例演示

模板会预设：

- 工作流类型
- 论文章节
- 处理强度
- 项目名称
- 示例文本（仅在选择示例时）
- 作者依据与修改位置（返修信示例）
- 专业术语锁（翻译示例）

模板不会自动生成或预填虚构实验事实。

### 3. 最近任务搜索

支持按以下信息搜索：

- 项目名称
- 目标期刊
- 工作流类型
- 论文章节

同时支持按四种工作流筛选任务历史。

### 4. 本地工作区备份

备份文件包含：

- 当前草稿
- 工作流配置
- 术语锁
- 最近任务历史
- Agent 运行结果
- 问题列表
- 作者决策

备份格式为 JSON，可用于浏览器之间或设备之间的手动迁移。

### 5. 本地工作区恢复

- 校验 ScholarForge 备份格式和版本
- 导入前明确提示会覆盖当前浏览器数据
- 最多恢复最近 8 条任务记录
- 不读取或保存账户密码、百炼 API Key

### 6. 本地数据清理

用户可删除：

- 当前草稿
- 全部本机任务历史

该操作不会删除 Supabase 账户身份。

### 7. 快捷键

- `Ctrl / Cmd + K`：聚焦项目历史搜索
- `Alt + H`：从任务工作台返回项目中心

## 数据边界

当前项目中心是浏览器本地能力：

| 数据 | 当前存储位置 |
| --- | --- |
| 登录身份 | Supabase Auth 或本地访客会话 |
| 当前草稿 | 浏览器 localStorage |
| 任务历史 | 浏览器 localStorage |
| 作者决策 | 随任务快照保存在 localStorage |
| 百炼 API Key | 仅服务端环境变量 |
| 模型处理文本 | 提交任务时发送至 Next.js 服务端与阿里云百炼 |

v0.9 不宣称已实现按用户隔离的云端论文数据库。

## 验收路径

1. 登录或以访客身份进入应用。
2. 查看项目中心首页。
3. 分别使用四个工作流的空白任务与示例入口。
4. 从任务工作台按 `Alt + H` 返回项目中心。
5. 完成任务后查看最近记录、待处理数量和平均准备度。
6. 使用搜索和工作流筛选。
7. 导出本地工作区备份。
8. 清除本地数据。
9. 导入备份并确认草稿和历史恢复。
10. 在 375px、768px、1440px 与宽屏环境检查布局。
