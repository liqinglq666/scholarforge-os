# 产品说明

## 定位

ScholarForge OS 是一款**阻止高风险 AI 修改直接进入科研论文的安全审校工作台**。首要用户是研究生、科研人员和学术编辑。

它不以“让 AI 多写一些”为目标，而是解决：

> 在保留原文、责任边界和作者决定权的前提下，如何检查 AI 修改是否仍然忠实于科研事实？

## 核心价值

1. 模型只生成候选稿和问题说明，不直接覆盖作者工作稿。
2. 代码独立检查数值、单位、引用、术语、实验声明和科研主张边界。
3. 不安全候选返回可解释的隔离结果，而不是模糊错误。
4. 原文、AI 候选稿和作者工作稿始终分离。
5. 作者逐条接受、拒绝或暂缓；没有批量静默应用。
6. 每次局部应用都会重新执行唯一文本锚点和安全检查。
7. 论文项目、导师意见、版本和历史默认保存在当前浏览器，可备份和恢复。

## 页面与完成定义

| 页面 | 用户目标 | 完成条件 |
| --- | --- | --- |
| `/` 首页 | 立即理解独特价值、技术架构和责任边界 | 用户知道系统审查的是 AI 修改本身，并知道如何开始 |
| `/try` 直接体验 | 无需登录完成推荐核心流程 | 案例载入、发送确认、安全门结果、逐条决定和导出路径清晰 |
| `/workspace` 快速审校 | 提供一个明确分析任务 | 正文 40–12,000 字符，任务和章节明确，发送内容已确认 |
| 审校结果 | 核对结果并形成作者工作稿 | 先看到安全门，再处理问题；危险候选不获得自动应用权限 |
| `/projects` 论文项目 | 管理整篇论文的章节和上下文 | 章节、术语、目标期刊、意见与版本归属清晰 |
| `/trust` 安全与测试 | 理解检查范围和已知限制 | 用户能区分硬规则、模型建议和未覆盖风险 |
| `/guide` 使用手册 | 独立完成体验 | 不依赖口头讲解、下载、部署或用户 API Key |
| `/settings` 数据与隐私 | 理解服务、备份与数据边界 | 能导出或恢复备份，并清楚知道哪些数据会发送 |

## AI、代码与作者责任

### AI 可以

翻译、保守润色、识别表达和报告风险、生成候选稿、提供原文证据和理由。

### AI 不能

确认科研事实、验证引用内容、证明统计正确、判断伦理合规、确认期刊最新规则、预测录用，或自行决定某条修改可以安全应用。

### 代码负责

请求和输出结构校验、科研事实硬规则、安全隔离、局部建议权限、唯一文本锚点、重叠检测、撤销和重做。

### 作者负责

核对事实、数据、统计、引用、研究设计、伦理、期刊要求和最终文本。

## 当前支持

- 科研中译英、英文保守润色、投稿前检查；
- DOCX 正文提取和清洁 DOCX 导出；
- 多论文项目和最多 12 个章节；
- 跨章节样本量、单位指标、缩写和术语一致性检查；
- 导师意见拆分、状态和作者回复；
- 版本比较、历史、撤销、重做和 JSON 备份；
- 可选 Supabase 登录和个性化偏好同步。

登录只用于偏好同步，不自动上传论文正文、导师意见、版本全文或分析历史。

## 当前不支持

PDF/OCR、公式和表格结构化编辑、参考文献真实性核验、统计审查、伦理判断、期刊实时规则核验、整篇论文自动生成、自动审稿回复、团队实时协作、原样式 DOCX、Word 修订痕迹和自动发表判断。

## 明确不采用的设计

- 未配置模型时生成模拟分析；
- 模型自行决定 `safeToApply`；
- 一键应用全部建议；
- 不可解释的投稿分数或录用预测；
- 把模型轨迹、Agent ID 和内部遥测当作用户价值；
- 在未证明数据治理完整前同步论文全文。
