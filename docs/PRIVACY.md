# 数据与隐私说明

此文档描述 ScholarForge OS v3 仓库的默认行为。部署方仍需根据实际模型供应商、日志、数据区域和组织政策补充正式隐私政策与服务条款。

## 浏览器本地数据

论文项目、章节正文、导师意见、版本全文、分析结果、作者决定、作者工作稿和历史记录默认保存在当前浏览器 `localStorage`。它们不会自动跨设备同步。

清理站点数据、关闭无痕窗口、浏览器策略或设备损坏可能导致丢失。用户可以导出 JSON 备份；导入失败不会覆盖当前工作区。

## DOCX

DOCX 在浏览器中读取。原始二进制文件不会上传或持久化。提取范围只包括可用正文，复杂公式、表格、批注、脚注、修订痕迹和原始排版需要作者回到源文件核对。

## 模型请求

只有用户查看发送内容并确认后，系统才向 `POST /api/review` 发送：

- 当前明确选择的正文；
- 项目或任务名称；
- 任务和章节类型；
- 目标期刊或写作语境；
- 术语规则。

服务端把这些内容发送给配置的阿里云百炼兼容接口。供应商的数据使用、保留和区域规则取决于部署方账户与合同，本仓库不能代替部署方做出承诺。

## 可选账户与云端偏好

Supabase 登录是可选功能。登录只用于同步经过验证的个性化偏好，例如学科、英文变体、默认任务、目标期刊语境、术语规则和章节模板。

登录不会自动上传：

- 论文正文或 DOCX；
- 导师意见；
- 版本全文；
- 分析历史和作者决定；
- 作者工作稿。

未配置 Supabase 时，应用继续以游客本地模式运行。

## 服务端日志

应用代码不主动记录论文正文、API Key或完整模型响应。未预期异常可记录请求 ID、错误类型和必要诊断信息。部署平台、代理、WAF、Supabase或模型供应商可能有独立日志；部署方必须检查脱敏、访问权限和保留期。

## 安全限制

浏览器本地存储不是加密保险库。不要在共享或不受信任设备上处理未公开、受协议约束或高敏感科研内容。公开部署前应完成组织的数据保护、伦理、合同和跨境传输评估。

科研事实安全门用于降低 AI 修改风险，不验证原始数据、统计正确性、引用内容或伦理合规。
