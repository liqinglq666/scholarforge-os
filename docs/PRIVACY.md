# 数据与隐私说明

此文档描述仓库 v2 的默认行为。部署方必须根据实际模型供应商、日志、区域和组织政策补充正式隐私政策。

## 浏览器本地数据

当前草稿、分析结果、作者决定、作者工作稿和最近任务保存在当前浏览器 `localStorage`。它们不会自动跨设备同步。清理站点数据、无痕窗口关闭、浏览器策略或设备损坏可能导致丢失。

用户可以在“数据与设置”导出 JSON 备份或清除全部本地工作区数据。

## DOCX

DOCX 在浏览器中读取。原始二进制文件不会上传或持久化。提取范围只包括可用正文；复杂对象需要作者在原文件中核对。

## 模型请求

只有作者查看发送内容并确认后，系统才向 `POST /api/review` 发送：

- 所选正文；
- 项目名称；
- 任务和章节类型；
- 目标期刊文本；
- 术语锁。

服务端把这些内容发送给配置的阿里云百炼兼容接口。供应商的数据使用、保留和区域规则取决于部署方账户与合同，本仓库不能代替部署方做出承诺。

## 服务端日志

代码只在未预期异常时记录请求 ID 与错误对象，不主动记录请求正文。部署平台、代理、WAF 或模型供应商可能有独立日志；部署方必须检查并配置脱敏、访问权限和保留期。

## 安全限制

本地存储不是加密保险库。不要在共享或不受信任设备上处理未公开、受协议约束或高敏感科研内容。公开部署前应完成组织的数据保护、伦理、合同和跨境传输评估。
